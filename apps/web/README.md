# AirQR Web

## Dev

```bash
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Python bundle (offline runtime)

```bash
python ../../build/python_bundle.py
```

Output:

- `dist/web-python`

## Single-file HTML

From the repo root:

```bash
python build/web_singlefile.py
```
