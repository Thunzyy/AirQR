AirQR — animated QR file transfer

Encode a file into animated QR codes on one screen and scan it with another device to rebuild the original. No account, cable, or shared network is required.

This interactive web demo needs JavaScript. Files are encoded and decoded on your device.

Download AirQR for Android, Windows and Linux, or get the offline HTML app.
